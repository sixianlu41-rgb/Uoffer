# Uoffer AI 训练营网站

静态 HTML5/CSS3 网站，包含：

- `index.html`：AI 训练营课程列表
- `course-detail.html`：AI 商业实战营详情
- `fde-detail.html`：AI Native Engineering 与 FDE 实战营详情

## 在线发布

GitHub Pages 设置：从 `main` 分支的根目录 `/ (root)` 发布。项目已包含 `.nojekyll`，无需构建步骤。

## 字体与资源

英文和数字使用 Sofia Pro，中文使用思源黑体。网页加载本地 WOFF2 字体文件。所有页面和资源使用相对路径，兼容 GitHub Pages 仓库子路径。

## 交互

课程跳转、导航下拉、锚点定位、FAQ 展开收起、咨询二维码弹窗及底部报名横条。横条关闭后本次隐藏，刷新后恢复。

## 本地查看

在项目目录启动静态网页服务器，打开 `index.html`。
